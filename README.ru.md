# ZenWidget

> **Язык:** [English](README.md) · **Русский**

Виджет с коллекцией расслабляющих миниигр. Живёт поверх других окон на десктопе и работает как обычное приложение на мобильных. Сделан для тех моментов, когда хочется отвлечься на 30 секунд — но не залипнуть на сессию.

**Принципы:** ни таймеров, ни game over, ни очков. Спокойная картинка, лёгкий по ресурсам, каждая игра самодостаточна.

---

## Зачем это

Ты работаешь или учишься, и нужно куда-то деть руки на минуту. Большинство «казуалок» — никакие не казуалки: у них цели, лидерборды, реклама, регистрация. ZenWidget — про обратное: лопнуть пузырей, провести граблями по песку, посмотреть на лавовую лампу, вернуться к делам. И всё.

## Установка

Готовые сборки приложены к каждому релизу. Выбери свою платформу:

### macOS

1. Скачай `.dmg` из [Releases](../../releases).
2. Открой и перетащи ZenWidget в Applications.
3. **Первый запуск:** правый клик по приложению → **Открыть** → **Открыть**. Это нужно один раз, потому что я не подписывал приложение в Apple Developer Program. Дальше запускается обычно.

### Windows

1. Скачай `.msi` из [Releases](../../releases).
2. Запусти. SmartScreen скажет «Защитник Windows заблокировал…» — нажми **Подробнее** → **Выполнить в любом случае**.
3. Ищи иконку ZenWidget в системном трее.

### Linux

1. Скачай `.AppImage` из [Releases](../../releases) (работает почти везде).
2. `chmod +x ZenWidget*.AppImage && ./ZenWidget*.AppImage`
3. Или возьми `.deb` для Debian/Ubuntu и поставь через `sudo dpkg -i`.

Требования: композитный window manager для прозрачности (GNOME, KDE, Cinnamon — да; голый i3 — нет).

### iOS / Android

Раздаётся через TestFlight (iOS) или в виде APK (Android), когда готов очередной релиз. Ссылку ищи в release notes.

## Сборка из исходников

Понадобится Node.js 18+, Rust (stable) и платформенный тулчейн (Xcode для macOS/iOS, Visual Studio Build Tools для Windows, Android Studio для Android).

```bash
git clone <этот-репо>
cd swiper
npm install
```

### Десктоп (Tauri)

```bash
# Запуск с hot reload
npm run tauri dev

# Релизные сборки (.dmg / .msi / .AppImage / .deb)
npm run tauri build
```

Артефакты появятся в `src-tauri/target/release/bundle/`.

### Мобильные (Capacitor)

Первая инициализация:

```bash
npx cap add ios       # macOS + Xcode + CocoaPods
npx cap add android   # Android Studio + JDK 17
```

Дальше sync и открытие нативного проекта:

```bash
npm run cap:ios       # открывает Xcode
npm run cap:android   # открывает Android Studio
```

Сам бинарник собираешь уже внутри IDE.

### Кросс-платформа через GitHub Actions

Workflow в [.github/workflows/build.yml](.github/workflows/build.yml) собирает **macOS, Windows и Linux параллельно** при пуше тега версии:

```bash
git tag v0.1.0
git push origin v0.1.0
```

Получаешь черновик GitHub Release со всеми бандлами.

## Архитектура

Всё — **vanilla JS + Canvas**. Никакого бандлера, никакого фреймворка, никаких npm-зависимостей в рантайме. Слои Tauri и Capacitor оборачивают одну и ту же папку `src/` в нативные шеллы.

```
src/
├── index.html          — реестр игр, runtime-определение платформы
├── style.css           — переменные, режимы .tauri / .capacitor / .macos / .windows / .linux
├── core/
│   ├── gameManager.js  — регистрация, переключение, rAF-цикл, throttle 30/10 FPS, ResizeObserver
│   ├── widgetShell.js  — drag (мышь + тач), сворачивание, picker, mute, close
│   └── audio.js        — Web Audio API singleton: tick / clack / pop / motor / fire / sand
└── games/
    └── <name>/index.js — одна игра = один файл
```

### Контракт игрового модуля

Каждая игра — default-export объект:

```js
export default {
  name:   'bubbles',           // уникальный id (camelCase)
  label:  'Пузыри',            // имя в picker'е
  icon:   '🫧',                // emoji в плитке picker'а

  init(canvas, ctx, opts) {},  // инициализация, вешает listeners
  update(dt) {},               // каждый кадр, dt в мс
  handleInput(event) {},       // опционально — большинство игр сами вешают listeners
  pause() {},                  // виджет скрыт
  resume() {},                 // виджет снова виден
  destroy() {},                // снять listeners, обнулить ссылки — обязательно полностью
}
```

### Соглашения

- **Никаких внешних зависимостей** в `src/`. Ни npm, ни CDN.
- **Анимация только через `requestAnimationFrame`.** `setInterval` допустим лишь для не-визуальных эффектов.
- **FPS-throttle** централизован в `gameManager.js` через timestamps, без отдельных таймеров.
- **Память:** не аллоцировать в update-цикле. Object pool, если активных частиц больше ~50.
- **Очистка:** каждый `addEventListener` обязан иметь пару `removeEventListener` в `destroy()`. Никто не подстрахует.
- **Никаких `console.log`** в коммитах.
- **Никакого `localStorage` / cookies / сетевого I/O.** Виджет автономен.

## Как добавить свою игру

1. Создай `src/games/<name>/index.js` по контракту выше.
2. Зарегистрируй в `src/index.html`:

```js
import myGame from './games/myGame/index.js';
// ...
manager.register(myGame);
```

3. Добавь строчку в таблицу этого README (и `CLAUDE.md`, если контрибутишь).

Готово — picker, drag, resize, mute, FPS-throttle и пауза при скрытии работают «из коробки».
